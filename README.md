# CodeAlpha Machine Learning Internship

This repository contains the machine learning tasks completed as part of the CodeAlpha Internship.

## Tasks Completed

### Task 1 - Credit Scoring Model
A machine learning model for predicting credit scores using customer financial data.

### Task 2 - Emotion Recognition from Speech
An audio classification model that recognizes emotions from speech using MFCC features and machine learning.

### Task 3 - Handwritten Character Recognition
A CNN-based image classification model for recognizing handwritten digits/characters.

### Task 4 - Disease Prediction from Medical Data
A Random Forest classification model for predicting heart disease from medical data.
